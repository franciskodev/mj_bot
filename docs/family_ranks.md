# Семейные ранги и должности

Ранг хранится в поле `users.family_rank`, по умолчанию — `young`.
Бот определяет его по Discord-ролям участника. Если ролей несколько, выбирает
старший ранг в порядке таблицы. Если ранговых ролей нет, используется `young`.

| Ранг | Discord-роль |
| --- | --- |
| young | 1533059446308339782 |
| main | 1533059442277613651 |
| old | 1540754418461577406 |
| high famq | 1533059426053914827 |
| deputy leader | 1533059422211936286 |
| tech | 1533059417665175723 |
| leader | 1416536370343579728 |
| curator | 1543030993240203326 |
| owner | 1433122505203253418 |

Для смены ранга измените роли участника в Discord. Бот обновляет базу при
изменении ролей, сохранении участника, запуске, периодической синхронизации
и просмотре профиля через `/myinfo` или `/user view`. Синхронизация сама
не выдаёт и не снимает Discord-роли. При принятии новой заявки выдаётся `young`,
как и раньше. Роли, временно снятые для Mafia, учитываются до их восстановления.

Должности хранятся отдельно в `users.recruitment_positions` и показаны в профиле:

- Рекрутёр — роль, настроенная для сервера через `/applications roles`, либо
  роль участников отдела рекрутёров из существующих настроек отдела.
- Deputy Chief Recruit — `1533059430223184043`.
- Chief Recruit — `1533059428331421757`.

Должности совместимы с любым рангом. Их выдача и снятие не меняют семейный ранг.
Уровни допуска продолжают определяться существующей системой доступа.
Все ранговые роли учитываются как семейные; синхронизация ограничена основным
Discord-сервером `1278169762140258367`.
