# Защита сообщений бота в журналах

В `config.py` список `PROTECTED_LOG_CHANNEL_IDS` включает общий журнал, журнал безопасности, анкеты, активность, управление, повышения, апелляции, отработку выговоров, выговоры, серверные теги, ошибки чата и пересылку ЛС. Защита также действует в доступных боту ветках этих каналов.

За подтверждённое удаление сообщения этого бота человеком снимаются доступные роли удалившего. Используется общая система защиты: исключения разработчика уровня 6, владельца сервера и пользователей с ролью выше бота сохраняются. Наличие Administrator само по себе исключения не даёт. Действия самого бота и других ботов не наказываются как действия человека.

Уведомления идут в общий журнал и канал `1548474347419734136`. Снятые роли попадают под трёхчасовой контроль возврата.

Одиночные удаления определяются по автору сообщения, каналу и исполнителю из аудита. Бот обрабатывает как новые записи, так и рост счётчика уже известной записи, исключая повторную обработку одного значения счётчика.

Для массового удаления бот сопоставляет удалённые ID с кэшем и таблицей `protected_log_messages`. Хранятся только ID сообщений, сервера и канала. При подключении бот индексирует недавнюю историю журналов; новые сообщения учитываются по мере получения. Сохраняется пятнадцать дней ID: это покрывает четырнадцатидневный период допустимого массового удаления с запасом. Первичная индексация требует доступа к истории; до её завершения авторы некоторых старых некэшированных сообщений могут быть неизвестны.

В [аудите Discord](https://docs.discord.com/developers/resources/audit-log#optional-audit-entry-info) для удаления нет ID конкретного сообщения. При массовом удалении проверяются канал, количество сообщений, время и наличие сообщений этого бота. Если несколько записей подходят одинаково или исполнитель не подтверждён, бот сообщает о проблеме вместо автоматического наказания наугад.

Для работы нужны права бота на просмотр каналов и истории, просмотр аудита, отправку уведомлений и управление ролями. Включён `Intents.moderation`, необходимый для [событий аудита disnake](https://docs.disnake.dev/en/stable/api/events.html#disnake.on_audit_log_entry_create). Новая таблица создаётся автоматически при запуске.
