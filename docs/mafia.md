# Мафия для Discord

Модуль асинхронного Discord-бота на Python и [disnake](https://github.com/DisnakeDev/disnake). Бот проводит текстовую игру в мафию с голосовым обсуждением: распределяет тайные роли, переключает фазы, принимает действия и голоса, определяет победителя и ведёт рейтинги.

Состояние партии хранится в PostgreSQL. После перезапуска бот продолжает игру, а временно снятые административные роли остаются в очереди восстановления.

## Возможности

- Партии на 6–12 игроков, одна активная игра на настроенном сервере.
- Автоматическое создание отдельной категории с текстовыми и голосовыми каналами.
- Мирные жители, мафия, доктор и комиссар; личные меню без необходимости открывать личные сообщения.
- Таймеры ночи, обсуждения и голосования, пауза и отмена партии.
- Доступ к игре по семейным ролям и управление с 5 уровня допуска.
- Временное снятие административных ролей игроков с сохранением допуска к командам бота.
- Семь видов рейтингов за всё время, последние 7 или 30 дней.

## Установка и настройка

Мафия входит в состав бота и подключается через [bot.py](../bot.py). Следующие команды запускают весь проект.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

В Windows активируйте окружение командой `.venv\Scripts\Activate.ps1` в PowerShell.

1. Создайте приложение и бота в Discord Developer Portal. Включите **Server Members Intent** и **Message Content Intent**, которые использует проект.
2. Подготовьте PostgreSQL и заполните локальный `.env` по [шаблону](../.env.example). Не публикуйте файл с настоящими токенами и реквизитами базы.
3. Проверьте [config.py](../config.py): идентификаторы сервера, разработчика, семейных ролей и остальных каналов проекта должны соответствовать вашему развёртыванию.
4. Пригласите бота на сервер с поддержкой slash-команд. Выдайте права **Управлять каналами** и **Управлять ролями**. Для автоматического переноса выбывших также нужно право **Перемещать участников**. В игровых каналах бот должен иметь возможность отправлять сообщения, читать историю и встраивать ссылки.
5. Разместите роль бота выше ролей игроков, чьи административные права будут временно сниматься.
6. Запустите бота:

```bash
python main.py
```

Таблицы и изменения схемы создаются автоматически при подключении к базе. Для применения обновлений кода перезапустите процесс бота.

### Настройки доступа

| Настройка | Назначение |
| --- | --- |
| `GUILD_ID` | Сервер, на котором работает мафия |
| `FAMILY_MEMBER_ROLE_ID` | Общая семейная роль |
| `TARGET_ROLE_IDS` | Дополнительные семейные роли |
| Активные семьи в базе | Их роли также дают право участвовать |
| `DEVELOPER_USER_ID` | Пользователь с постоянным 6 уровнем допуска к боту |

Игрок должен иметь хотя бы одну семейную роль. Сам по себе высокий допуск или право Discord **Administrator** не заменяет семейную роль. Проверка выполняется при вступлении, перед стартом и при изменении состава ролей.

Уровни доступа к командам определяются в [access_control.py](../access_control.py). Длительности фаз и предел числа раундов заданы константами `MAFIA_NIGHT_SECONDS`, `MAFIA_DAY_SECONDS`, `MAFIA_VOTE_SECONDS` и `MAFIA_MAX_ROUNDS` в `config.py`.

## Быстрый старт

1. Пользователь с допуском 5 или 6 выполняет `/mafia create`.
2. Бот создаёт категорию партии и публикует панель в канале `события`.
3. Игроки нажимают **Присоединиться**. Организатор тоже должен нажать эту кнопку, если хочет играть.
4. Когда соберутся 6–12 участников, организатор нажимает **Начать**.
5. Бот подготавливает разрешения каналов и временно снимает административные роли игроков. После этого участники узнают свои роли через **Моя роль / действие**.
6. Дальнейшие фазы переключаются автоматически. Управлять паузой и отменой можно кнопками на панели.

Набор игроков и приостановленная партия считаются активной игрой: создать вторую до завершения или отмены первой нельзя.

## Команды

Параметры в квадратных скобках необязательны. Их выбирают в интерфейсе slash-команд Discord.

| Команда | Назначение | Допуск по умолчанию |
| --- | --- | --- |
| `/mafia create` | Создать категорию, комнаты и лобби новой партии | 5 |
| `/mafia status [game_id]` | Показать текущую или указанную игру и восстановить удалённую панель | 1 |
| `/mafia top [metric] [period]` | Показать топ-10 по выбранному показателю и периоду | 1 |
| `/mafia stats [user]` | Показать статистику выбранного игрока или свою | 1 |

Порог создания игры защищён: его нельзя понизить через `/access command`. Начать, поставить на паузу, продолжить и отменить партию могут только пользователи с допуском 5–6. Отмена требует отдельного нажатия кнопки подтверждения.

## Комнаты партии

Каждая партия получает отдельную категорию с номером игры и служебным суффиксом, который помогает восстановить создание после сбоя.

| Канал | Тип | Назначение и доступ |
| --- | --- | --- |
| `события` | Текстовый | Панель, вступления, смена фаз, смерти, голосования, паузы и результат. Видит семья; пишет бот |
| `обсуждение` | Текстовый | Видит семья; живые участники могут писать в лобби и во время дневных фаз |
| `чат-мафии` | Текстовый | Во время партии виден живой мафии; писать можно ночью |
| `Обсуждение` | Голосовой | Живые участники могут подключаться; говорить — в лобби и дневных фазах |
| `Выбывшие` | Голосовой | Общение выбывших игроков |
| `Мафия` | Голосовой | Закрытое ночное обсуждение живой мафии |

Права тайных комнат назначаются конкретным игрокам. Выбывшие теряют возможность говорить и писать в обсуждении живых. Если выбывший находится в войсе этой партии, бот переносит его в комнату выбывших при наличии необходимых прав и с учётом иерархии ролей. Разработчик исключён из автоматического переноса.

Бот не устанавливает серверный mute, не подключается к войсам и не переносит участников из посторонних каналов. Общение за пределами категории игры не ограничивается.

После завершения или отмены категория сохраняется как архив. Обычным участникам запрещаются сообщения и новые подключения к игровым войсам. История не удаляется автоматически.

## Роли и правила

### Состав партии

| Игроков | Мафия | Доктор | Комиссар | Мирные |
| --- | --- | --- | --- | --- |
| 6–8 | 2 | 1 | 1 | Остальные участники |
| 9–12 | 3 | 1 | 1 | Остальные участники |

Роли распределяются случайно. Кнопка **Моя роль / действие** открывает ответ, видимый только самому игроку. Мафия видит состав своей команды и её текущие ночные выборы, комиссар — историю своих проверок. Чтобы обновить информацию, откройте меню заново.

### Фазы

| Фаза | Время по умолчанию | Действия |
| --- | --- | --- |
| Ночь | 60 секунд | Мафия выбирает жертву; доктор защищает игрока; комиссар проверяет игрока |
| Обсуждение | 120 секунд | Бот сообщает результат ночи, участники обсуждают подозрения |
| Голосование | 60 секунд | Живые участники выбирают другого игрока или воздерживаются |

**Ночью:**

- Жертвой становится единственный лидер голосования мафии. При равенстве голосов или отсутствии выбора убийства нет.
- Доктор может защищать себя и повторять защиту одного игрока несколько ночей подряд. Защита предотвращает убийство этой ночью.
- Комиссар получает ответ «Мафия» или «Не мафия». Проверить себя нельзя. После получения ответа сменить цель этой ночью невозможно.
- Мирные жители не выполняют ночных действий.

**На голосовании:**

- Против себя голосовать нельзя.
- Выбывает единственный лидер голосования. Если лидеры набрали одинаковое число голосов или победило «Воздержаться», никто не выбывает.
- Не проголосовавшие игроки не учитываются при подсчёте.

Ночной выбор мафии и доктора, а также дневной голос можно менять до окончания фазы. Меню прошлых фаз и меню, открытые до паузы, недействительны.

Выбывшие не голосуют и не выполняют ночных действий. Уход с сервера или потеря семейной роли исключает участника из лобби либо текущей игры. Отключение от голосового канала само по себе не исключает игрока. Роли раскрываются публично после завершения или отмены партии.

### Победа

- **Город** побеждает после устранения всей мафии.
- **Мафия** побеждает, когда живых мафиози становится не меньше, чем остальных живых игроков.
- Если за 20 раундов победитель не определился, объявляется **ничья**.

## Временное снятие административных ролей

Право Discord **Administrator** позволяет обходить ограничения видимости каналов. Поэтому перед раскрытием игровых ролей бот:

1. Сохраняет в PostgreSQL идентификаторы административных ролей игрока и его исходный допуск к командам.
2. Снимает только роли, дающие **Administrator**.
3. Проверяет, что административные права сняты, и настраивает доступ к комнатам партии.

Уровень доступа к командам бота сохраняется. Это распространяется и на разработчика: его административные роли временно снимаются, а допуск остаётся равным **6**.

Роли возвращаются после завершения или отмены партии, включая роли выбывших игроков. До конца игры выбывшим административные права не возвращаются. Если возврат не удался, запись восстановления сохраняется и бот повторяет попытку после восстановления связи или перезапуска. Ушедший с сервера игрок сможет получить роли после возвращения и завершения партии.

Пока роли после прошлой партии не возвращены, вступить в новую игру нельзя. Удалённые с сервера роли бот не создаёт заново.

### Ограничения

- Иерархия Discord действует для всех игроков, включая разработчика. Для снятия и возврата ролей роль бота должна находиться выше нужных ролей и текущей высшей роли игрока.
- Роли интеграций нельзя временно снять таким способом.
- Семейная роль не должна одновременно давать **Administrator**: разделите семейную и административную роли.
- Владелец сервера не может участвовать: его права нельзя ограничить снятием роли.
- Администраторы вне игры сохраняют видимость закрытых комнат.

Подробности описаны в [документации Discord о разрешениях](https://docs.discord.com/developers/topics/permissions). Если подготовка не удалась, игра остаётся на паузе. Пользователь с сохранённым допуском 5–6 может отменить её; возврат ролей не зависит от доступности каналов партии.

## Рейтинги

В `/mafia top` доступны следующие показатели:

| Показатель | Значение параметра `metric` |
| --- | --- |
| Очки | `points` |
| Победы | `wins` |
| Сыгранные партии | `games` |
| Процент побед | `win_rate` |
| Победы за мафию | `mafia_wins` |
| Победы за город | `town_wins` |
| Выживания | `survived` |

Периоды: всё время, последние 7 или 30 дней. Учитывается дата завершения партии.

За победу начисляются **3 очка**, за поражение или ничью — **1 очко**. Победа считается всем игрокам победившей команды, включая выбывших. Отменённые партии в статистику не попадают.

Для попадания в топ процента побед нужно завершить хотя бы **5 игр за выбранный период**. Личная статистика показывает процент побед и при меньшем числе партий.

## Хранение данных и восстановление

| Таблица PostgreSQL | Содержимое |
| --- | --- |
| `mafia_games` | Игроки, роли, действия, фаза, таймеры, пауза и идентификаторы комнат |
| `mafia_results` | Результаты завершённых партий для статистики |
| `mafia_role_holds` | Временно снятые роли, сохранённый допуск и состояние возврата |
| `mafia_events` | Очередь публичных уведомлений и отметки об отправке |

После перезапуска просроченная фаза завершается, а следующая получает полное время. Пауза сохраняется. Финал и результаты записываются одной транзакцией, поэтому повторная обработка не начисляет очки дважды. Прерванное создание комнат возобновляется по сохранённым идентификаторам и меткам.

Рабочая база содержит Discord ID, тайные роли и игровые действия. Не публикуйте её дампы вместе с исходным кодом.

## Устранение неполадок

| Симптом | Что проверить |
| --- | --- |
| Нельзя создать игру | Допуск не ниже 5; отсутствие другой активной партии; права бота на управление каналами и ролями |
| Игрок не может вступить | Наличие семейной роли; свободное место; завершён ли возврат ролей после прошлой игры |
| Старт заблокирован | Число игроков, их семейные роли, иерархию ролей бота и отсутствие неснимаемых административных прав |
| Подготовка остаётся на паузе | Доступность PostgreSQL и Discord, права бота, положение его роли. Бот повторяет подготовку |
| Панель удалена | Выполните `/mafia status`; бот восстановит панель |
| Роли не вернулись | Наличие игрока на сервере, существование ролей, права и иерархию бота. Очередь восстановления сохраняется |
| Меню сообщает об устаревшем действии | Снова нажмите **Моя роль / действие** |

## Разработка и проверки

Основные файлы:

- [cogs/mafia.py](../cogs/mafia.py) — slash-команды, компоненты Discord и цикл обновления партии.
- [cogs/mafia_game.py](../cogs/mafia_game.py) — правила и переходы между фазами.
- [cogs/mafia_rooms.py](../cogs/mafia_rooms.py) — комнаты, разрешения, снятие и возврат ролей.
- [database.py](../database.py) — схема, транзакции, события и статистика.
- [tests/](../tests/) — проверки правил, доступа, восстановления и работы с PostgreSQL.

Из корня проекта с активированным виртуальным окружением:

```bash
python -m unittest discover -s tests -v
```

Интеграционные тесты создают отдельный временный PostgreSQL-кластер и не подключаются к рабочей базе из `.env`. Нужны серверные утилиты `initdb` и `pg_ctl`; если они не установлены, интеграционные тесты пропускаются. Запускайте их от обычного пользователя, поскольку `initdb` не работает от `root`.
